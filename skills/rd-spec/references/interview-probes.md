# 拷问诊断与探针

> 📎 从 `skills/rd-spec/SKILL.md` 抽出。**加载条件**：拷问开始时。
> 不读会：退回固定问卷 —— 用户已经写清边界还要按表问一遍，
> 这正是流程被弃用的方式。四透镜诊断、六类工程问题诊断化、档位探针、组合检查都在这里。

## 这是 agent 内部诊断，不是给用户看的清单

**含糊的开场白可能触发三四个探针，而一个具体、框得很好的开场白可能一个都不触发。**
探针要**折进对话的自然流程**，不是开场先打一梭子。
把下面这张诊断表原样打印给用户 = 把内部工具当成了交付物，是最典型的失败。

## 四个缺口透镜 —— 产品维度，先问这一层

先诊断开场白缺哪一类，缺了才问。命中就按对应探针问，没命中就跳过。

| 透镜 | 诊断什么 | 命中了就问 |
|---|---|---|
| **证据缺口** | 只说了「想要 / 需要」，没指向任何**已经发生过的行为** | 关于这件事，有人已经做过的最具体的一件事是什么——花过时间、付过钱、搭过绕行方案、还是因此弃用过某个工具？ |
| **具体性缺口** | 受益人抽象到 agent 不编造「他是谁」就没法设计 | 说出一个具体的人或一小撮人，以及这东西上线后对那个人**具体变了什么** |
| **反事实缺口** | 没说清今天遇到这问题用户怎么办，也没说不做会怎样 | 现在的绕行方案是什么？哪怕很难看。它让他们付出了什么？ |
| **依恋缺口** | 把某个**解法形状**当成了要做的东西，而不是那个形状本该交付的**价值** | 还能交付真实价值的最小版本长什么样？ |

**产品维度探针在前，它决定还要不要往下问**：这四个透镜挖出来的东西
（具体是谁、他今天怎么绕、最小版本是什么）**恰好是写出好 `checkIntent` 的原料**。
挖不出受益人 / 绕行方案 / 最小版本，后面的工程问题问得再细，写出来的验收标准也是空转。

## 六类工程问题 —— 先诊断，缺了才问

原来「每类至少一个具体问题」是固定问卷。改成：**开场白已经把哪类写清楚了，那一类就不问。**

| 类别 | 要逼出什么 | 开场白里算「已经写了」的标志 |
|---|---|---|
| **失败路径** | 输入非法、依赖挂了、并发撞了、超时了，分别怎么办 | 明说异常时的行为或已有兜底设计 |
| **边界值** | 空、0、极大、超长、重复提交、乱序到达 | 明说具体边界值及其处理 |
| **权限与可见性** | 谁能做、谁能看、跨租户/跨用户怎么隔离 | 明说角色划分与隔离规则 |
| **数据兼容** | 存量数据怎么办、schema 变不变、能不能回滚 | 明说存量处理与迁移方案 |
| **不做什么** | 明确排除项 —— 这条最容易漏，也最容易让 agent 越界 | 已明确列出排除项 |
| **判定方式** | 每条要求"你怎么知道它做对了" | 已给出可观察的判据 |

## 探针深度跟着档位走

先读 `dispatch.md` 的复杂度档位，据此决定问多深：

| 档位 | 探针深度 |
|---|---|
| **S** | 只问三问：是不是解决真问题 / 是不是重复造轮子 / 有没有零成本的更好框法。问完即止 |
| **M** | 标准四透镜 + 六类诊断（缺了才问） |
| **L / XL** | M 全部 + 产品级追问：这东西什么情况下会失败？我们可能顺手建错哪个相邻产品？用户哪天会想拆掉它？ |

**这张表约束的是 rd-spec 的完整拷问流程。**精简策略有自己的探针范围，**不许按本表对它们加码**：

- `guarded` 只问三件事（失败路径 / 不做什么 / 判定方式），不走六类全套；
  四透镜诊断只在开场白含糊到影响这三问时用，不是标配。
- `refactor-safe` 只问边界三问（对外行为变不变 / 禁改文件 / 基线可信度）。
- `direct` 不加载本文件。
- 探针永远**折进对话的自然流程**，不是开场先打一梭子；开场白已经写清的类别直接跳过。

**S 档三问在本仓库任何策略里都不会触发**（direct 不加载本文件）——保留它是因为
future 若给 S 级需求也开 rd-spec，需要一个最轻的入口；当前实际只会用到 M / L / XL 三行。

## 组合检查 —— 退出拷问的前置条件

一问一答有个固有缺陷：**每个答案都对，合起来有洞。**

退出对话前，把用户到目前为止说过的话**在脑子里合起来**，
找出对话没探过的非显然后果。如果「用户说的 X ＋ 用户说的 Y ＋ 你的默认 Z」
会产生一个用户在一问一答里不太可能追踪到的下游效果
（「如果静音挂在规则上，而且删除时不警告，那删规则就会静默丢掉暂停状态」）
——**现在就问，趁还在对话里**。

配一条纪律：后面的确认环节是**残余项的安全网，不是你本可以现在问却偷懒不问的问题的垃圾桶**。
