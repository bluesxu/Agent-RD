# wf-keep

任务做完后，判断有没有经验值得长期留下。

**这个 skill 的价值在于「不记什么」。**
lessons 如果什么都收，最后就是垃圾桶：越写越长、越写越乱，
检索时命中一堆无关条目，agent 反而更难抓住重点。

## 什么值得进 lessons/

必须**同时**满足四条：

1. **适用于本次精确 diff 之外** —— 下次别的任务也会用上
2. **有可追溯证据** —— 能指到 `file:line` 或一次真实的失败
3. **能写成未来动作** —— "以后遇到 X 就做 Y"，不是感想
4. **没有现成的 canonical owner** —— 项目文档里已经写了的，不要复制一份

典型合格条目：

- 某类接口必须统一返回错误格式（因为前端统一在 X 处理）
- 模块 A 不能直接依赖模块 B（依赖方向约束）
- 某类 migration 必须带回滚说明
- 某个第三方库的坑：调用 X 之前必须先 Y，否则静默失败

典型**不合格**（留在 feature 目录里就好）：

- 登录接口改成了 `/api/v2/login` —— 一次性事实
- "要写好的代码" / "注意安全" —— 空泛口号
- 网络波动、拼写错误、环境问题 —— 噪声
- 已经被 lint / typecheck / 测试机械覆盖的规则 —— **优先机械化，不要写成 lesson**

> 能落成 red→green 测试或 checker 的约束，一律优先机械化。
> 机器能拦的东西不要交给 agent 的注意力去拦。

## 条目格式

写到 `.workflow/lessons/{YYYY-MM-DD}-{slug}.md`：

```markdown
---
status: observed
keywords: [auth, error-format, api]
source: features/user-login
---

# {一句话规则}

**动作**：以后 {什么情况} 就 {做什么}。

**为什么**：{真实的失败或取舍，带 file:line 或现象}

**排除了什么错误路径**：{这条规则帮你避开的具体错误做法}
```

### status 生命周期

| status | 含义 | 怎么变 |
|---|---|---|
| `observed` | 观察到一次，还没被复用验证 | 初始值 |
| `validated` | 后续任务真的用上了并且验证成功 | 只在独立的后续任务中确实采用并验证成功时升级，补一次代表性证据 |
| `retired` | 当前仓库事实直接反证，或发现了 canonical owner | 只写原因和替代/反证指针，不删文件 |

**检索到 lesson 时先做一次 read-repair**：做一次有界的、最低成本的定向核实
（读现有代码/测试/文档）。核实不了就跳过这条，**不要为了核实 lesson 去跑大范围测试**。

只有 scope 符合、未退役、当前事实成立、并且**真实改变了计划或验证**的条目才算有效命中。
命中时报告：`经验命中：{path}（{status}）；核验：{fact}；影响：{改变了什么}`。

只是相关但没改变行为的，不要制造复用证据。

## attention.md

`.workflow/attention.md` 是**每次开工必读**的那张便签。

规则：
- **保持短**。超过 30 行就说明该往 lessons 里搬了。
- 只放"不知道就会立刻踩坑"的当前事实：正在进行的迁移、临时的绕过、
  已知坏掉的东西、本周不能碰的模块。
- **有时效**。每次 `wf-keep` 都要顺手清掉已经过期的行。

## 收尾报告

```
📝 经验筛选 — {feature}

候选 {n} 条，采纳 {m} 条：
  ✅ lessons/2026-08-06-error-format.md  {一句话}
  ✅ lessons/2026-08-06-module-dep.md    {一句话}
机械化 {k} 条（已转为 checker/测试，不入 lessons）：
  🔧 {规则} → {test/lint 位置}
丢弃 {j} 条：{原因，一行}

attention.md：新增 {a} 行，清理过期 {b} 行
```

**没有值得沉淀的就明说"本次无采纳"，不要强行凑条目。**

## 硬门槛

- **写入 lessons 前要报告候选和理由**，让用户能一眼否决。
  这是个低成本确认，不是审批 gate —— 用户不回应就按你的判断写。
- **不许静默改写或删除已有 lesson**。`retired` 是标记，不是删除。
- **不许把一次性事实写进 lessons**。
- **不许因为"这次没什么好记的"而不调用本 skill** —— 显式报告"无采纳"也是结论。
